# Security policy
This is a learning system, not a bank-grade product. Do not use real customer, staff, account, sanctions, authentication or payment data. Report issues through a private GitHub security advisory. Before any real deployment add OIDC, RBAC, TLS, secrets management, encryption, rate limits, tamper-evident audit, dependency scanning, SAST/DAST, threat modelling, privacy controls, resilience and independent security review.
